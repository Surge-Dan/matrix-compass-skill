# Matrix Compass UI Phase A 实施记录

日期：2026-09-26
范围：经营总览、数据导入与同步、备份与安全的第一轮界面与交互收口。

## 已完成

- 将经营总览调整为“下一步该做什么”的决策视图：内容航向、关键指标、作品表现轨迹、值得继续的内容清单。
- 新增内容航向组件，使用继续 / 新增 / 实验 / 调整 / 收缩五种结论承接后续真实数据规则；当前演示数据展示为“继续”。
- 统一为冷白、石墨、罗盘蓝的系统化视觉语言，支持系统明暗主题、降低动态效果和移动端布局。
- 新增中文化的“数据导入与同步”流程：先选来源、字段对应、预览、确认写入、按批次回滚。
- 针对飞书迁移明确内容与收入的 CSV 字段，保留 CSV / XLSX 上传和手动粘贴两种入口。
- 增加“平台数据如何进入”说明：微信公众号为官方授权；小红书为用户主动导出后增量导入；抖音为官方经营授权。
- 新增“备份与安全”页，说明本地数据边界、导入/升级/恢复前自动备份以及恢复预演的原则。

## 安全边界

- 不读取浏览器 Cookie，不模拟登录，不绕过验证码或平台验证。
- 未实现的平台能力不会显示为可用同步；总览上的“立即同步”在连接能力落地前保持不可用状态。
- 普通数据备份不包含平台凭据；凭据后续应单独存于 Windows 凭据管理器。

- Node 24 下的单元与 UI 契约测试：24 / 24 通过。
- TypeScript `tsc --noEmit` 通过。
- 生产构建与构建产物自检通过，并完成 `/`、`/api/bootstrap`、`/api/dashboard`、`/api/health` 的构建后冒烟检查。

  - 390px 移动端总览与底部导航。

## 已知限制与下一阶段

- 当前“作品表现轨迹”和“内容航向”在演示模式使用示例数据；真实库只展示可证明的事实，未计算的数据不会伪造。
- 真实的微信公众号、抖音官方 OAuth/授权回调、凭据管理、增量同步任务尚未实现。
- 小红书当前设计为导出文件的增量导入，不承诺不存在的官方历史数据接口。
- 下一阶段应优先补齐：数据字段模型与导入映射预览、备份执行与恢复预演、官方连接的配置页及授权状态机。
