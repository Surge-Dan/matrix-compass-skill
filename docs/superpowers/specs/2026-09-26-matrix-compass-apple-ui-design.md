# Matrix Compass Apple 风格 UI 设计规格

状态：设计方向已确认，等待进入实施计划

日期：2026-09-26

适用范围：个人创作者经营实验室的桌面端看板、作品管理、导入、平台连接、备份与安全页面

## 1. 设计判断

Matrix Compass 是个人创作者使用的经营数据工具，不是面向团队的内容分发 SaaS，也不是单纯的数据报表。

首页必须优先回答：

> 最近发布的内容，哪些值得继续做，哪些应该调整？

视觉方向采用 Apple 式的清晰层级、低噪声动效、直接操作和系统级可访问性，同时加入与产品名称相关的“内容航向”组件，避免做成普通的卡片式数据看板。

本设计不使用反检测、私有接口重放、验证码绕过或 Cookie 偷跑作为平台连接方案。

## 2. 设计原则

1. 数据先于装饰：每个图表和洞察都能回溯到作品、平台记录或历史快照。
2. 判断先于展示：首页围绕“下一步做什么”组织信息，而不是平铺所有指标。
3. 一条作品是主语：一条作品可以关联多个平台发布记录、多个表现快照、多个收入记录和一份个人复盘。
4. 平台数据与个人数据分离：同步只能更新平台原始数据和历史快照，不能覆盖复盘、标签、问题和下一步动作。
5. 安全反馈克制但明确：备份失败、授权失效、导入错误等关键事件必须可见，普通运营提醒不主动打扰。
6. 优先使用中文：平台、账号、作品、收入、复盘等用户可理解的业务语言优先，只有必要的技术名词保留英文。

## 3. 视觉系统

### 3.1 设计参数

- 设计变化度：6/10
- 动效强度：5/10
- 信息密度：5/10
- 视觉重点：内容航向组件
- 页面主题：跟随系统，支持手动切换浅色和深色

### 3.2 颜色令牌

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F5F6F8` | `#101216` |
| 表面 | `#FFFFFF` | `#181B21` |
| 主文字 | `#16181C` | `#F3F5F7` |
| 辅助文字 | `#68707A` | `#A3AAB4` |
| 分隔线 | `#DCE0E6` | `#2B3038` |
| 主强调色，罗盘蓝 | `#356DFF` | `#78A0FF` |
| 正向状态 | `#27A878` | `#59D0A1` |
| 风险状态 | `#D98545` | `#F0AE6C` |
| 负向状态 | `#C95252` | `#F07878` |

平台品牌色只用于平台标记或图例，不作为页面主色。

### 3.3 字体

- 正文和控件：系统字体，优先 `-apple-system`、`SF Pro Text`、`PingFang SC`、`Microsoft YaHei UI`。
- 页面标题和作品主题：`Noto Serif SC` 或 `思源宋体`，仅用于标题、关键判断和作品名称。
- 数字：系统数字字体，开启等宽数字，避免数据更新造成布局跳动。
- 不使用大面积英文标题，不使用纯装饰性的英文小标签。

### 3.4 形状与层级

- 基础圆角：12px。
- 主要模块圆角：18px。
- 浮层和详情面板圆角：24px。
- 不使用大面积重阴影，主要依赖背景层级、分隔线和留白。
- 透明材质只用于顶部工具栏、右侧详情面板和少量状态浮层，并提供无透明度回退。

## 4. 全局页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│  Matrix Compass     最近30天   全部平台   全部账号   立即同步  │
├───────────────┬──────────────────────────────────────────────┤
│               │                                              │
│  总览         │                页面内容                       │
│  作品         │                                              │
│  账号         │                                              │
│  排期         │                                              │
│  收入         │                                              │
│  连接平台     │                                              │
│               │                                              │
│  备份与安全   │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

桌面端：

- 左侧导航宽度约 232px，固定显示。
- 顶部工具栏高度约 72px。
- 主内容最大宽度约 1320px，居中排列。
- 图表和列表采用 12 列网格，列间距 20px 到 24px。

移动端：

- 左侧导航收起为底部导航。
- 首页保留总览、作品、排期、收入、更多五个入口。
- 详情面板从底部以半屏或全屏方式展开。
- 表格转为作品卡片，不强行横向滚动。

## 5. 首页总览

### 5.1 顶部控制区

控件从左到右：

1. 时间范围：最近 30 天，支持周、月、季度、年度和自定义。
2. 平台筛选：默认全部平台。
3. 账号筛选：默认全部账号。
4. 立即同步：展示同步状态和最近同步时间。
5. 备份状态：展示最近一次备份是否成功。
6. 主题切换：跟随系统、浅色、深色。

顶部不放搜索框、导出、设置等低频操作，避免工具栏变成操作仓库。

### 5.2 内容判断区

标题示例：

> 最近 30 天，内容在变好

副标题示例：

> AI 工具实测的互动率和收藏率都高于你的个人平均。

右侧放“内容航向”组件，显示当前建议方向：继续、加码、试验、调整或收缩。

默认最多展示 1 条主洞察和 2 条次级洞察。每条洞察必须带有数据依据，不输出无法验证的泛化建议。

### 5.3 核心指标

默认显示四项：

- 发布数
- 总触达，按平台可用指标统一映射
- 互动率
- 已确认收入和待结算收入

指标卡不使用四个完全相同的彩色卡片，而是采用一条连续的指标带：统一表面、不同的底部状态线和轻量趋势标记。

### 5.4 内容表现轨迹

主图表标题：`作品表现轨迹`

默认展示最近 30 天的触达趋势，可切换互动率、粉丝增长和收入。

交互：

- 悬停某个日期时显示该日汇总。
- 点击某个日期后，在图表下方展开当日发布作品。
- 点击作品节点后打开右侧详情面板。
- 当前曲线以罗盘蓝为主色，其余指标降低对比度。

### 5.5 值得继续

右侧列表显示 3 条最值得继续观察的作品或内容类型。

每条包含：

- 作品主题
- 主要平台
- 核心表现
- 与个人平均的差异
- 一条微型趋势线

不使用“爆款”“必火”等夸张标签，只显示可验证的相对表现。

### 5.6 平台表现

使用平台横向对比和小型趋势线，显示：

- 发布数量
- 平均触达
- 平均互动率
- 粉丝变化
- 最近同步状态

平台数据不足时显示“样本不足”，不计算误导性的排名。

### 5.7 最近动态

动态来源包括：

- 新增作品
- 同步完成
- 导入完成
- 同步失败
- 备份完成或失败
- 待结算收入
- 待复盘作品

运营动态默认只进入列表，安全和数据完整性事件才触发系统通知。

## 6. 作品页

作品页是数据管理主入口，支持列表视图和轻量卡片视图。

### 6.1 筛选

- 时间范围
- 平台
- 账号
- 内容类型
- 标签
- 作品状态
- 是否有收入
- 是否待复盘

### 6.2 作品列表字段

- 内容主题
- 内容类型
- 平台发布记录数
- 发布时间
- 触达和互动
- 收入状态
- 复盘状态
- 最近同步时间

列表不默认展示 20 个以上字段。其余字段在详情面板查看。

### 6.3 新建作品

采用快速新建表单：

- 内容主题
- 内容类型
- 平台和账号
- 发布时间

保存后再进入详情补充：

- 链接
- 标签和系列
- 多平台发布记录
- 表现数据
- 收入记录
- 复盘
- 下一步动作

## 7. 作品详情面板

详情面板从右侧展开，宽度约 420px 到 480px，保留当前页面筛选条件。

结构：

1. 作品标题、状态和来源。
2. 多平台发布记录。
3. 表现数据曲线和快照时间轴。
4. 收入与结算记录。
5. 个人复盘。
6. 下一步动作。

平台原始字段使用浅色来源标记；个人编辑字段使用独立的编辑区域。同步后显示“平台数据已更新，个人复盘未改变”。

## 8. 导入流程

导入入口同时支持 CSV 和 XLSX。

流程：

```text
选择文件
  ↓
识别工作表和字段
  ↓
自动映射
  ↓
检查新增、重复和异常
  ↓
确认批量导入
  ↓
导入结果与撤销入口
```

飞书字段默认映射：

| 飞书字段 | Matrix Compass 字段 |
| --- | --- |
| 内容主题 | 作品标题 |
| 平台 | 平台发布记录 |
| 账号 | 平台账号 |
| 发布时间 | 发布时间 |
| 发布类型 | 内容类型 |
| 复盘 | 个人复盘 |
| 收入类型 | 收入记录类型 |
| 收入金额 | 收入金额 |
| 结算状态 | 结算状态 |
| 复盘亮点 | 复盘亮点 |
| 复盘问题 | 复盘问题 |
| 优化方向 | 下一步动作 |

导入规则：

- 不确定的映射必须标记待确认。
- 重复记录不静默覆盖。
- 错误行单独展示原因。
- 批量导入必须支持整体回滚。
- 导入前和导入后都生成备份记录。

## 9. 平台连接页

每个平台显示能力边界，不伪装成“全部已接入”。

```text
微信公众号   已连接
数据来源     官方接口
最近同步     今天 09:20
可用能力     内容记录、运营数据

小红书       导出导入
数据来源     用户主动导出
最近导入     9月25日
可用能力     账号资料、导出文件导入

抖音         需要经营授权
数据来源     官方经营授权
状态         等待授权或审核
```

B站和 YouTube 后续沿用相同的连接器模型，不改变作品、发布记录和表现快照的数据结构。

## 10. 备份与安全页

页面要让用户明确知道数据是否可恢复。

展示：

- 当前数据目录
- 最近一次成功备份
- 最近一次备份大小
- 备份保留数量
- 第二备份目录
- 当前数据库健康状态
- 最近一次恢复预演结果

操作：

- 立即备份
- 设置第二备份目录
- 运行恢复预演
- 导出可携带备份
- 查看备份记录

平台 Token 和 AppSecret 不进入普通数据备份，凭据单独存放在 Windows 凭据管理器。

## 11. 动效规范

- 按下控件立即反馈，不等待动画完成。
- 所有面板和图表动画从当前显示值继续，不从初始值重放。
- 普通 UI 使用临界阻尼弹簧，不产生夸张回弹。
- 图表筛选变化使用短距离连续过渡。
- 同步按钮显示“连接、读取、写入、完成”四阶段状态。
- 详情面板打开时内容先稳定出现，背景只做轻微层级变化。
- 支持 `prefers-reduced-motion`，减少动效时保留状态变化和焦点变化。
- 支持减少透明度和高对比度模式。

## 12. 空状态、加载和错误状态

### 空状态

主文案：`把过去的内容带回来`

操作：`导入已有记录`、`新建第一条作品`

### 加载状态

显示具体动作：

- 正在读取本地数据
- 正在整理表现快照
- 正在同步公众号
- 正在生成看板

不使用无意义的“加载中”。

### 错误状态

错误消息必须包含：发生了什么、影响范围、下一步操作。

示例：

> 小红书文件中有 7 行无法识别发布时间。其他 270 行尚未写入。修正文件后可以重新导入。

## 13. 实施边界

第一轮 UI 实现优先级：

1. 全局壳层和首页总览。
2. 作品列表和右侧详情面板。
3. CSV/XLSX 导入流程。
4. 账号和平台连接状态。
5. 备份与安全页。
6. 排期、收入和更多图表模块。

第一轮不做：

- 团队协作
- 自由拖拽和自由缩放布局
- 非官方平台私有接口抓取
- 复杂的 AI 自动写作
- 全自动后台定时发布

## 14. 验收标准

- 首页打开后 5 秒内能看懂最近内容表现和下一步方向。
- 所有图表都能点击到具体作品或数据快照。
- 同步数据不会覆盖个人复盘和收入备注。
- 导入 277 条飞书记录时可预览、可发现异常、可整体回滚。
- 小红书显示真实的导出导入状态，不伪装成完整 API 同步。
- 浅色和深色模式保持相同的信息层级。
- 键盘焦点、减少动效、减少透明度和高对比度模式可用。
- 移动端不出现不可操作的宽表格和横向溢出。
- 备份失败、授权失效和导入错误可以被追溯。
